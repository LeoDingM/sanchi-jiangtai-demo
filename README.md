# 《三尺讲台》

江西省宁川中学教学生活模拟。界面中文。学校、城市、人物、校史、喜报均虚构；现实参考宁都中学 2017—2020 年生态的数量级，不照搬真实姓名。

交付方式与《浮世万象》可玩版相同：原生 JavaScript + HTML/CSS + Canvas，本机 `python3 -m http.server` 即可打开。领域逻辑可在 Node 里跑自动测试，分数、排名、分班、分数线和录取都由确定性代码计算，不用 LLM 出分。

权威设计见 `项目总控-V1.1.md`。标定与数据来源见 `docs/CALIBRATION.md`。

## 玩家任教班

**2017 级卓行 16 班，约 73 人。**

选择卓行而非凌霄，是为了贴近总控里「普通班常规约 70 人、编制约 65–75」的量级；没有选择云岫 0/1 班（约 30—35 人的清北标准培养班）。开学时高一尚未正式文理分科，16 班为混合普通班；第一次分班后该班成为卓行理科班，玩家跟班至高考，该届毕业后再接任新高一卓行 16 班。

## 如何运行

测试：

```bash
cd /workspace/sanchi-jiangtai
node --test tests/*.test.js
```

可玩入口（浏览器）：

```bash
cd /workspace/sanchi-jiangtai
python3 -m http.server 8766 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8766/ 。也可直接用任意静态服务器指向本目录。需要 ES 模块，请不要用残缺的 `file://` 方式打开。

不使用 Unity。没有为 Unity 安装编辑器或 SDK。

## 现在能玩什么

- 从 2017 年 9 月 1 日起，以数学实习教师身份进入宁川中学。
- 教室座位表、学生档案、谈话、备课、上课。
- 日期与事件驱动校历：月考、期中、期末、市联考、省联考、高三模拟、高考。
- 高一 950 分制（8 门课，不含生物）；高二起理科开生物；高三/高考 750 分（理综 110/100/90，文综政史地各 100）。
- 每次考试可看任教班成绩，也可在教务处看全校总分和单科、按层次（云岫实验 / 重点、凌霄、卓行、笃学、艺体、复卓）筛选，对比同层次各班，并查看范围内单科第一。班级汇总全部由学生个人成绩加总。
- 第一次分班（文理分科 + 梯队晋级淘汰）与第二次分班（同层同科类均衡，不混用第一次规则）。
- 高考后按江西公开省控线与 2020 年投档对照表对应到真实大学，可查看学生去向。清北只有达到公开投档线才会出现。
- 毕业后游戏继续：高三离校或进入复卓复读，高二升高三、高一升高二，新高一入学，教师职业生涯延续。
- 自动模式可一键跳过阶段，直到本届高考录取，或再推进到下一届；跳过时仍生成成绩、排名并写入存档。
- 浏览器 localStorage 自动存档，另有三个手动槽和 JSON 文件导入导出。

## 成绩线如何随考试变化

每场考试有独立的难度和离散度（高考贴近当年省控线水平，其他场次抖动更大）。一本线、二本线由当次排序现算：分科后按科类分摊第 400 / 第 1000 名。题难则同样名次的原始分更低。临场发挥、试题契合、状态用种子决定，第一名不必场场同一人，第一第二名分差有时只有几分、有时拉开十几分以上。
